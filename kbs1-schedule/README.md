# KBS1 목적 편성표 · 연령대별 시청 흐름

KBS 1TV의 2026년 8월 25일(화)~31일(월) 편성을 횡선식 공정표 형태로 다시 그린 웹페이지입니다.

- 프로그램을 편성 목적 여섯 줄(팩트&시사, 지식&인사이트, 힐링&여행, 세대공감&휴먼, 공익&로컬, 실생활&안전)에 나눠 시간 막대로 보여줍니다.
- 막대마다 우측 상단에 시청등급과 방송구분(재방송, 지역 자체방송, UHD, 자막, 화면해설, 수어, 스테레오 등) 표식을 붙였습니다.
- 막대를 누르면 기획 의도 한 줄 요약이 나오고, 같은 날 같은 목적으로 편성된 프로그램 목록도 함께 보입니다.
- 연령대 버튼(어린이·청소년, 20·30대, 40·50대, 60대 이상)을 누르면, 그 연령대가 이어 볼 만한 프로그램들이 네트워크 공정표처럼 화살표로 연결됩니다.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 페이지 구조 |
| `style.css` | 디자인(라이트/다크 모드) |
| `data.js` | 7일 편성 데이터(시간, 프로그램명, 등급, 방송구분, 목적, 기획 의도 요약) |
| `audience.js` | 연령대별 관심 프로그램 표. 실제 연령대 시청률 자료가 생기면 이 파일만 바꾸면 됩니다 |
| `app.js` | 편성표 그리기, 화살표 연결, 상세 보기 |

빌드 과정은 없습니다. `index.html`을 브라우저로 열면 바로 동작합니다.

## 자료와 한계

- 편성, 시청등급, 방송구분, 기획의도: KBS 1TV 편성표(schedule.kbs.co.kr), 서울 기준.
- 목적 분류와 기획 의도 한 줄 요약은 KBS가 등록한 기획의도를 바탕으로 정리했습니다.
- 연령대별 연결은 실제 연령대별 시청률이 아니라, 기획의도에 적힌 주 시청층과 프로그램 성격으로 추정한 관심도입니다. 공개된 연령대별 시청률 자료를 찾지 못했기 때문입니다.
